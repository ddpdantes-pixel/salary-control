# Android: тестовая версия «Мой ритм» (задача 62)

Одна React-кодовая база используется в PWA и локально упакованном APK.
Постоянный package ID: `io.github.ddpdantespixel.moyritm`; он не связан с Dima AI.
Android origin: `https://localhost`. Данные PWA с GitHub Pages автоматически не появляются в APK.

## Инструменты

- Node.js 24.19.0 (Capacitor требует Node 22+), pnpm 11.7.0.
- Capacitor core/CLI/Android 8.5.3; версии зафиксированы в package.json и pnpm-lock.yaml.
- Android Gradle Plugin 8.13.0, Gradle wrapper 8.14.3, JDK 21.
- Android SDK: compile/target 36, min 24. Android Studio 2025.2.1 или новее.
- На этом ПК Studio 2026.2.1; JDK для Gradle: `C:\Users\User\.jdks\jbr-21.0.11`.
  JBR 25, на котором работает сама Studio, не используйте для Gradle 8.14.3.

## Сборка на Windows

Откройте терминал в основной папке репозитория и задайте переменные только этой сессии:

```powershell
$env:JAVA_HOME = 'C:\Users\User\.jdks\jbr-21.0.11'
$env:ANDROID_HOME = 'C:\Users\User\AppData\Local\Android\Sdk'
$env:PATH = 'C:\Temp\codex-node\node-v24.19.0-win-x64;' + $env:PATH
pnpm install --frozen-lockfile
pnpm run build:android
pnpm exec cap sync android
Push-Location android
.\gradlew.bat :app:assembleDebug
Pop-Location
```

Эквивалент последним трём шагам: `pnpm run android:apk`.
Каждая следующая тестовая сборка должна снова пройти web build, sync и Gradle build.
Браузерная сборка отдельна: `$env:BASE_PATH='/salary-control/'; pnpm run build`.
Android build всегда использует `/` и `dist-android`, без PWA service worker.
Для исходной папки с кириллицей проект включает `android.overridePathCheck=true`;
это снимает предварительный Windows path guard AGP, не перемещая репозиторий.
PWA остаётся в `dist` с существующей конфигурацией; GitHub Pages не отключается.

## Android Studio

Запустите `pnpm exec cap open android` или откройте папку `android/` как отдельный проект
в новом окне Studio. Не открывайте её внутри Dima AI.
В Settings → Build, Execution, Deployment → Build Tools → Gradle выберите JDK 21
для этого проекта. Нажмите Sync Project with Gradle Files.
SDK можно указать через переменную `ANDROID_HOME` либо локальный `android/local.properties`.
Локальные настройки IDE/SDK, build outputs и ключи подписи не входят в Git.

Проект и зависимости проверены реальной Gradle-сборкой с JDK 21. На финальной
проверке команда открытия Studio отработала, но IDE не предоставила доступного окна.
Поэтому открытие проекта и успешный Gradle Sync именно в IDE пока не подтверждены.
Не считайте эту проверку пройденной только по сообщению `cap open`.

## APK и установка

Файл: `android/app/build/outputs/apk/debug/app-debug.apk`.
Это debug APK для синтетических данных, versionCode 1 / versionName 1.0.

Передайте файл на Samsung, откройте его в «Мои файлы» и разрешите установку
из этого источника, когда Android предложит. Либо подключите телефон с USB debugging:

```powershell
adb devices
adb -s <serial-вашего-Samsung> install -r android/app/build/outputs/apk/debug/app-debug.apk
```

Не используйте команду uninstall для обновления: она удаляет данные приложения.
Проверьте Главное, Зарплату, Деньги, Здоровье; ввод тестовых значений, Back,
клавиатуру, тёмную тему, выбор файла, export/share, offline и повторный запуск.
Окончательная приёмка возможна только после проверки на Samsung Galaxy S26.

## Перенос данных и установленное ограничение

В PWA: Зарплата → История → «Сохранить резервную копию в файл».
В APK: Зарплата → История → «Восстановить из файла», выбрать JSON,
проверить preview и подтвердить восстановление. Используется существующий формат v10,
а не второй Android backup. Облачное восстановление использует прежний ключ подключения
и прежний Worker. Ключ подключения переносится отдельно; не публикуйте его.

Backup сохраняет зарплату, продажи, финансы, обязательства, цели, изображения целей,
Health history/недельные отметки/долги, настройки, Кубышку и зашифрованное хранилище паролей.
В существующем формате намеренно отсутствуют скриншоты здоровья из
`moi-ritm-health-temporary/attachments`; это подтверждено текущими backup-тестами.
Полный перенос этих вложений через backup НЕ гарантирован. Сохраните их отдельно в PWA
и не удаляйте исходную PWA. Для автоматического полного переноса нужна отдельная
согласованная задача по backup; задача 62 не меняет формат и не очищает историю.
Apple Health sync secret также не экспортируется существующим контрактом.

До устранения ограничения не переносите реальные данные в эту тестовую APK.
Android сохраняет прежние localStorage/IndexedDB в приватном WebView-хранилище приложения.
Они сохраняются при перезапуске и обновлении той же подписью; удаление приложения,
сброс его данных или смена package/origin лишают доступа к этому хранилищу.

## Android-адаптеры и ограничения

- SystemBars применяет нативные insets; клавиатура использует resize.
- Back сначала вызывает существующее безопасное закрытие dialog, затем внутреннюю
  навигацию и только на корне предлагает свернуть приложение.
- Backup/изображения сохраняются через Android Storage Access Framework без полного
  доступа к накопителю. File picker использует стандартную поддержку Capacitor WebView.
- Share передаёт полный набор cache-URI через официальный Capacitor Share;
  общий JPEG для ChatGPT и генератор отчёта остаются прежними.
- Кэш переданных изображений приватный; его контролирует Android. Исходные вложения
  из IndexedDB при отправке не удаляются.
- PDF отчёт открывает стандартный Android PrintManager.
- Сетевые функции требуют интернет. Web Push PWA не заменяется нативными push в этом этапе.

## Подпись release

Debug APK подписывается стандартным debug-ключом этого ПК. Для постоянной версии нужно
вместе с пользователем создать и безопасно сохранить собственный release keystore.
Debug и release обычно имеют разные подписи; Android может потребовать переустановку.
Перед переходом обязательно сохранить backup и отдельно все скриншоты здоровья.
Keystore, пароли и signing secrets не коммитить; в задаче 62 release-ключ не создаётся.
