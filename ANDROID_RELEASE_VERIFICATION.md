- Samsung release-миграция не проводилась. Debug APK и PWA остаются как были.
  Дальнейшие действия только по `ANDROID_RELEASE_MIGRATION.md`, после отдельного

  Перед удалением debug нужные оригиналы необходимо сохранить отдельно.
  Копирование текста/ручное прикрепление скриншотов и share-код не изменялись.
  Ранее подтверждённый native share этапа 62 не является новым тестом приёма файлов
  приложением ChatGPT на Samsung. Такой приём здесь не заявляется проверенным.
- При смене системной темы во время работы API 37 цвет значков status bar иногда
  остаётся от предыдущей темы. После закрытия и нового запуска цвет корректен

  менять существующий UI или выпускать неподтверждённую повторную APK ради него
  в задаче подписи не стали. На Samsung требуется отдельная проверка.
- Независимая резервная копия keystore рекомендована, но ещё не подтверждена.

HealthState, FinanceState, схемы localStorage/IndexedDB, Worker/D1, backup contract,
